# 侯娇 · 个人作品集

React 19 + Vite 7，按用户指定的本地参考站布局迁入。默认预览：http://127.0.0.1:4174/。

## 运行

`pnpm install`、`pnpm dev`；构建：`pnpm build`。

## 内容维护

- `src/main.jsx`：Hero、优势、联系区。
- `src/Navigation.jsx`：双层固定导航。
- `src/About.jsx`：个人介绍、折叠经历、微信复制。
- `src/Works.jsx`、`src/works.json`：15 个系列的封面、图片与展开内容。
- `src/AIVideo.jsx`：三段 AI 视频。
- `src/style.css`：最大 1700px 版心与响应式布局。
- `public/media`、`public/works`：参考项目中的本地视频、头像、作品及方案文件。

首页继续使用《踏春：一次有趣的出行》，静音循环，可暂停。已保留侯娇 / HOU JIAO 及真实联系方式，个人介绍和底部均支持微信复制。

迁入前的源代码保存在 `.qa/before-reference-layout/src`；原始作品与参考项目均未修改。当前只提供本地预览，尚未发布公网。
